# Script words (The Old Falcons, as SVG)

Generated by `tools/script_svg.py` from the licensed desktop font. `fill="currentColor"`, so color comes from the surrounding text token.
File names: `script-dope.svg` = "dope", `script-dope-cap.svg` = "Dope", `-caps` = all caps.
`script-actually-dope-tilted.svg` is set at -9 deg, the angle of the BOAST lockup scrawl.

To add a word: add it to `content/copy/en.json` -> `scriptWords`, then
`python3 tools/script_svg.py --out brand/script "word"` and run the result through svgo before it ships.
Never ship the font file itself.
